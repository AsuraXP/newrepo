# newrepo — video production

Shared workspace for making narrated video projects.

## Start here

1. **`VIDEO_PIPELINE_PROMPT.md`** — the prompt. Paste it into a fresh
   conversation; it assumes nothing.
2. **`PROJECTS.md`** — every project in this repo, its state, and what is
   allowed to be touched.
3. **`examples/<project>/`** — one directory per video. That project's script,
   frames, continuity file, metadata and build inputs live there.

## The one rule

This repository is shared across conversations and across projects. Finished and
abandoned work sits next to current work, and none of it is a style guide.

The prompt governs process. The current project's brief governs the video.
Everything else in here is machinery or history.
